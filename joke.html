Sobre

Esta página busca piadas de APIs públicas (primeiro icanhazdadjoke, com fallback para JokeAPI). As piadas são carregadas no cliente via fetch; nenhuma piada é armazenada no servidor.

  • Algumas APIs retornam piadas em inglês — caso queira apenas em português, posso adaptar com tradução automática.
  • Se a API falhar, uma mensagem de erro aparecerá.
