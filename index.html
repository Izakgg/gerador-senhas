Sobre

Este gerador usa a API segura do navegador para criar senhas aleatórias. Ajuste o comprimento e os conjuntos de caracteres para equilibrar usabilidade e segurança.

  • Recomendado: 12 caracteres ou mais para senhas humanas; 16+ para senhas aleatórias de alto risco.
  • Use um gerenciador de senhas quando possível.
